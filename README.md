# Infuse - Custom DI Container for .NET

**Author:** Pieter Neyt

## Project Structure

- `Infuse.Framework/` - The DI container framework
- `Infuse.Demo/` - Demo console application
- `Infuse.Tests/` - Unit tests

## Build & Run

### Build all projects
```bash
dotnet build
```

### Run demo application
```bash
dotnet run --project Neyt.Demo/Neyt.Demo.csproj
```

### Run tests
```bash
dotnet test
```
